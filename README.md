# Calendar Task Master (TaskFlow) 任务管理系统

这是一个基于 Web 技术 (HTML/CSS/JS) 构建的现代化本地优先任务管理应用，集成了日历视图与层级任务管理功能。项目采用 Glassmorphism (毛玻璃) 设计风格，支持文件系统访问 API (FileSystem Access API) 进行数据持久化。

## 📁 项目文件结构分析

### 1. `index.html` (应用结构与界面)
这是应用的入口文件，定义了整体的 DOM 结构。
*   **头部 (Header)**: 包含 Logo、视图切换器 (日历/任务视图) 以及文件操作按钮 (新建、连接、设置)。
*   **视图容器 (Main)**:
    *   `#view-calendar`: 日历视图容器，包含月份导航和日历网格。
    *   `#view-task`: 任务列表容器，用于展示 L1-L3 的层级任务结构。
*   **模态框 (Modals)**:
    *   `#settings-modal`: 全局设置，主要用于主题切换。
    *   `#day-modal`: 每日详情弹窗，用于管理选中日期的具体任务 (排期/完成)。
    *   `#date-modal`: 日期范围选择器，用于设置任务的开始和结束时间。
*   **资源引用**: 引入了 Google Fonts (Outfit) 和本地的 `style.css`、`script.js`。

### 2. `script.js` (核心逻辑与状态管理)
核心业务逻辑层，主要包含以下模块：
*   **状态管理 (`state`)**: 维护当前日期、任务数据、视图模式、文件句柄及当前主题。
*   **数据持久化**:
    *   **LocalStorage**: 实时同步，防止刷新丢失。
    *   **FileSystem Access API**: `connectFile`/`saveData` 实现与本地 JSON 文件的读写同步 (含防抖机制)。
*   **任务逻辑**:
    *   **三级层级**: 支持 L1 (项目/根任务) -> L2 (阶段/子任务) -> L3 (具体执行项) 的嵌套结构。
    *   **进度计算 (`calculateProgress`)**: L1/L2 的进度由其下属所有 L3 任务的完成率自动计算得出。
*   **渲染逻辑**:
    *   `renderCalendar()`: 动态生成月视图，并在日期格内渲染 Gantt 风格的任务条 (L1/L2)。
    *   `renderTaskList()`: 递归渲染层级任务列表。
*   **主题系统**: `applyTheme()` 动态切换 CSS 类名以应用不同配色方案。

### 3. `style.css` (样式与设计系统)
采用 CSS Variables 实现灵活的主题系统和响应式布局。
*   **设计风格**: 
    *   **Glassmorphism**: 大量使用 `backdrop-filter: blur(12px)` 和半透明背景 (`--glass-bg`) 营造现代感。
    *   **CSS 变量**: 定义了 `--accent-color`, `--bg-color` 等核心变量，便于一键换肤。
*   **主题定义**:
    *   默认深蓝 (Default)
    *   `.theme-warm` (暖黄琥珀)
    *   `.theme-pink` (亮粉霓虹)
    *   `.theme-fresh` (清爽海洋)
*   **布局技术**:
    *   使用 Grid Layout (`calendar-grid`) 实现日历的自适应排列。
    *   使用 Flexbox 处理头部、任务行和模态框的对齐。
*   **组件样式**: 包含自定义复选框、进度条、各种交互按钮及 SVG 图标的样式适配。

## 🚀 核心功能

1.  **双视图切换**: 
    *   **日历视图**: 宏观查看任务排期，今日任务高亮，支持任务条展示。
    *   **任务视图**: 树状结构管理任务拆分，支持无限级(目前逻辑限制为3级)扩展。
2.  **本地文件同步**: 支持直接读写本地 `.json` 文件，数据完全由用户掌控，无需服务器。
3.  **多主题支持**: 内置 4 套精心设计的配色方案，满足不同视觉偏好。
4.  **智能排期**: 支持父子任务时间校验 (子任务时间必须在父任务范围内)。

## 🛠 使用说明

1.  推荐使用 Chrome 或 Edge 浏览器以获得最佳的 FileSystem API 支持。
2.  点击右上角 "连接" 按钮打开现有的数据文件，或 "新建" 开始新项目。
3.  在任务视图创建一级任务，随后逐级拆分。
4.  在日历视图点击具体日期，可将三级任务安排到该天执行。
